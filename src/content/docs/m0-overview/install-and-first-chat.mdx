## 常用命令

| 命令                        | 作用                                 |
| --------------------------- | ------------------------------------ |
| `hermes model`              | 选择 LLM provider 与模型             |
| `hermes tools`              | 配置启用的工具                       |
| `hermes config set` / `get` | 设置 / 读取单个配置项                |
| `hermes gateway`            | 启动消息网关（Telegram、Discord 等） |
| `hermes setup`              | 一次性完整配置向导                   |
| `hermes doctor`             | 诊断问题                             |
